EcoPulse - Windows x64

KULLANIM
1. EcoPulse-Windows-x64.zip dosyasini bir klasore cikarin.
2. EcoPulse.Dashboard.exe dosyasina cift tiklayin.

Docker, Python veya ayri bir .NET kurulumu gerekmez. Simulasyon ve veritabani
uygulamanin icindedir. Veriler bilgisayarda su klasorde tutulur:
%LOCALAPPDATA%\EcoPulse\ecopulse.db

Bu paket Windows x64 icindir. Her bilgisayar kendi yerel verisini tutar.
